# EVAL Barbershop (Minsk) - Landing Page

Учебный проект в рамках программы Rolling Scopes School.
Двухстраничный адаптивный веб-сайт премиального барбершопа **EVAL** (Минск).

## Структура репозитория
- Ветка main содержит базовую конфигурацию репозитория.
- Разработка Части 1 (Вёрстка, Адаптивность, Темы) ведётся в ветке landing-page.
- Разработка Части 2 (Интерактивность) ведётся в ветке landing-page-part-2.
